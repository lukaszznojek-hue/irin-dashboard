# Sales - Materiały handlowe IRIN

> Navigator: kiedy co używać

## Mapa katalogów

```
sales/
├── per_szkolenie/     ← ZACZNIJ TUTAJ przed rozmową o konkretnym szkoleniu
├── per_persona/       ← emaile i argumenty pod konkretny typ klienta
├── uniwersalne/       ← skrypty i emaile do dowolnego szkolenia

```

## Skróty

- **KFS** = Krajowy Fundusz Szkoleniowy (do 90% dofinansowania dla mikrofirm)
- **BUR** = Baza Usług Rozwojowych PARP (IRIN ID 160205, ocena 4.9/5)
- **P3** = Priorytet PARP: AI i cyfryzacja (klaster 01-04)
- **P4** = Priorytet PARP: sektor zdrowotny i opiekuńczy (klaster 05-10)
- **Tier 1** = szkolenia aktywnie sprzedawane | **Tier 2** = monitorowane | **Tier 3** = lead-gen
